# Результаты проверки стратегий контекста

Дата подготовки: 2026-09-13.

## Контролируемые проверки

- Прошли `go test ./internal/session -run 'Test(ParseFacts|SlidingWindow|Facts|Branch|Restart)' -count=1 -vet=off`.
- Прошли `TestSlidingAndFactsRestartAfterPruningRetainTranscriptAndBoundedMemory`:
  для Sliding Window и Facts с `N=3` после четырёх пар, restart и пятой
  отправки UI содержит 8→10 сообщений, agent memory остаётся `<=3`, а usage не
  теряется. Это защищает загрузку уже pruned диалогов.
- Прошёл `TestSummaryCannotChangeStrategyAfterCompactEmptiesAgentMemory`:
  `/compact` не позволяет сменить Summary на Sliding Window, даже когда в памяти
  агента больше нет сообщений, но UI-переписка сохранена.
- Прошёл весь `npm run test:e2e`: 17 из 17. В него вошли legacy-сценарии
  создания, токенов, overflow, title, удаления и admin polling, а также
  стратегии, Summary `/compact`, branching, Facts и large-message.
- E2E использует локальный fixture provider. Его facts usage — синтетические
  `7/3`; это не измерение модели. Проверены явный выбор, блокировка смены после
  первого сообщения, Facts, изоляция веток, отказ `/compact` вне Summary и
  мобильная ширина.
- Ручная проверка через CUA на `1440×900` и `390×844` подтвердила явный выбор,
  Facts, две изолированные ветки, Summary `/compact`, отказ `/compact` вне
  Summary и прокрутку боковой панели. Все наблюдаемые usage в этой проверке
  также относятся к fixture.
- Реальный provider не вызывался. Auto-review не разрешил передачу локального
  API key в запрос `/models`; это же ограничение применяется к серии сравнений.
