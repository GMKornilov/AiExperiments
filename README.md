# Минимальный Go-клиент для LLM API

Программа читает YAML-конфигурацию, принимает сообщения из консоли, отправляет их в OpenAI-совместимый API `POST /chat/completions` и печатает текст первого ответа.

## Запуск

1. Создайте локальный конфиг и укажите ключ:

   ```sh
   cp config.example.yaml config.yaml
   ```

2. Отредактируйте `config.yaml`: заполните `api_key`; при необходимости измените `base_url` и `model`.

3. Запустите:

   ```sh
   go run ./cmd/llm-chat
   ```

4. Введите сообщение после `>>> `. Ответ будет напечатан с префиксом `<<< `. Чтобы завершить программу, передайте EOF: `Ctrl+D` в macOS/Linux.

`config.yaml` добавлен в `.gitignore`, поэтому ключ не попадёт в Git. Для другого OpenAI-совместимого провайдера укажите его базовый URL без конечного `/chat/completions`.

## Структура

```text
cmd/llm-chat/       точка входа
internal/config/    чтение и проверка YAML-конфигурации
internal/llm/       HTTP-клиент OpenAI-совместимого API
```

Каждый запрос ограничен параметром `request_timeout`. Пустое введённое сообщение не отправляется в API.
