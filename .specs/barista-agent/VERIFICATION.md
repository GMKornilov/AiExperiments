## Большой промпт: производительность и DeepSeek (2026-09-11)

Один диагностический запрос с docs/deepseek-overflow-prompt.txt отправлен в реальный
настроенный API (основная модель, system prompt и большой user prompt). Получен HTTP
400 примерно за 27 секунд: maximum context 1048576 tokens, requested 6000348 tokens.
Поле code/type — invalid_request_error. Это подтверждённое переполнение; ответ не
содержит usage, эти числа не добавляются к учтённому расходу.

Реальный ответ воспроизведён фикстурой: клиент распознаёт context_limit; HTTP-тест
с 14 МБ проверяет неизменность отправленного текста и error_category в DTO сообщения.
