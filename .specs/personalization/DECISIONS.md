# Решения: персонализация ассистента

## Принятые решения

- Профили принадлежат browser-сеансу; один профиль активен для всех его
  проектов и чатов.
- Встроенные неизменяемые профили: «Бариста» и «Специалист по кофейному
  оборудованию». По умолчанию активен «Бариста».
- Кастомный профиль создаётся вручную отдельной формой из уникального имени
  длиной до 60 Unicode-символов и трёх обязательных свободных текстов: стиль,
  ограничения и дополнительный контекст. Лимита длины у каждого поля нет.
- Удалять можно только кастомный профиль и только после подтверждения. Удаление
  активного профиля выбирает «Бариста».
- Приоритет намеренно абсолютный: `системная безопасность > активный профиль >
  текущий чат > project memory > global memory`.
- Профиль не является слоем памяти: он не извлекается автоматически и не
  изменяет факты памяти.

## Риски и открытое решение

- Отсутствие предела длины каждого из трёх полей может превысить доступный
  контекст модели. Владелец: Human. До отдельного решения не обещается числовой
  latency или context-size budget.
