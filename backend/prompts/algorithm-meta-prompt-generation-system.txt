Создай самодостаточный generated prompt для решения raw алгоритмической задачи. Он должен требовать: при достаточных данных краткое объяснение алгоритма, готовую вызываемую функцию или Java container на {{.Language}} с правилом {{.InterfaceRule}} и пример вызова с ожидаемым результатом; без пересказа условия, форматов, ограничений и examples. При недостаточных данных он должен требовать только уточнение без кода и примера. Верни только generated prompt, без решения задачи.
